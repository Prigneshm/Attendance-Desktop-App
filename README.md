# eSSL Attendance Integration Suite

Software to integrate eSSL biometric attendance devices with an organization's HR and payroll workflows — syncing attendance logs, managing employees, and configuring devices from a single interface.

## Overview

Organizations using eSSL biometric attendance hardware often rely on manual exports and ad-hoc scripts to get punch data out of the devices and into usable records. This project replaces that with a direct integration layer built on the eSSL SDK, giving administrators one place to pull logs, manage employee records, and configure connected devices.

## Features

- **Automated log synchronization** — pulls attendance logs from connected eSSL devices on a schedule, eliminating manual exports.
- **Employee management** — add, update, and remove employee records directly from the application, with changes reflected on the connected devices.
- **Device configuration** — configure and manage multiple eSSL devices (network settings, enrollment, time sync) from a central console.
- **eSSL SDK integration** — communicates with device hardware natively through the eSSL SDK rather than relying on manual file exports.
- **Intuitive interface** — a straightforward UI so non-technical staff can manage devices and review attendance without IT involvement for routine tasks.

## Impact

- Reduces manual effort in attendance data collection and reconciliation.
- Improves accuracy of attendance records by removing manual transcription/export steps.
- Scales to additional devices and locations as an organization grows, without adding administrative overhead.
